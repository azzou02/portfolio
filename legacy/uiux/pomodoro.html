Pomodoro Timer

2025

A playful take on the classic Pomodoro technique, built around a custom hand-drawn tomato illustration that doubles as the timer display. Instead of a generic countdown clock, the numbers sit inside an illustrated tomato "screen," with a second tomato character standing by to react when time's up — because staring at a plain digital clock for 25 minutes is nobody's idea of fun.

Design — Warm, appetite-appealing palette (coral, tomato red, golden yellow) that leans into the theme without tipping into clip-art territory. The illustration is the interface — no separate clock face bolted onto a mascot. Rounded pill buttons and an italic serif wordmark keep the tone friendly and a little editorial, not sterile "productivity tool." Minimal UI chrome so the tomato stays the star.

Features — Three session modes: Pomodoro, Short Break, Long Break. Start/reset controls. A sound alert plays when time's up, and the companion tomato switches to a yawning GIF — a small reward/punishment gag for finishing (or losing focus during) a session. Manual session switching keeps the user intentional about starting their next block.

Stack — React (frontend), Node.js (backend), HTML/CSS. Designed and illustrated the tomato characters, then built the full front end and backend — timer logic, state management, and wiring up the sound and GIF trigger on completion.

Challenges — Layout was the trickiest part. Fitting UI elements naturally inside an irregular, hand-drawn shape — rather than a clean rectangular container — took a lot more careful alignment and iteration than a standard flat-UI layout would have.
